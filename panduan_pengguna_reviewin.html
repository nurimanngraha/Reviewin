Standard Operating Procedure (SOP)

Panduan Operasional Sistem Reviewin

Buku pedoman teknis dan tata laksana pemanfaatan Kartu Pintar Dual-Engine (Barcode QR & NFC NTAG213) untuk optimalisasi ulasan Google Review.

Platform: Reviewin / CreTech Hardware Target: NTAG213 & QR Code Target Pengguna: Admin, Pemilik Bisnis, Pelanggan

Ringkasan Peran & Tanggung Jawab Tiga Aktor

Aktor Perangkat / Alat Tanggung Jawab Utama Hasil Akhir
1. Administrator (CreTech) Dashboard Admin, HP/NFC Writer (NFC Tools), Printer QR Registrasi perangkat, cetak QR, write URL ke chip NTAG213 Kartu fisik siap kirim (status: Unactivated)
2. Pemilik Bisnis (Merchant) Smartphone kamera/NFC, Kemasan Kartu (Kode Kartu) Tap/Scan pertama kali, input kode aktivasi, hubungkan Google Place Kartu aktif (status: Active), siap di kasir
3. Pelanggan (Customer) Smartphone pribadi (iPhone / Android) Tap kartu NFC atau scan Barcode QR di meja kasir Langsung memberi rating bintang 5 di Google Review
A
1. Panduan Pengguna: ADMINISTRATOR (CreTech)
Bertanggung jawab atas penciptaan aset perangkat, penulisan chip NFC, dan pencetakan kartu fisik.
Langkah 1 Pendaftaran Perangkat di Dashboard Admin
  • Buka dashboard Admin Reviewin pada menu Perangkat (Devices) → klik Tambah Perangkat Baru.
  • Pilih tipe perangkat: QR + NFC.
  • Sistem akan secara otomatis men-generate:
    • Device Code unik (misal: DEV-820192).
    • Kode Kartu / Activation Code (misal: ACT-492019).
  • Simpan perangkat. Status default perangkat adalah Unactivated.
Langkah 2 Pengambilan URL NFC & Unduh Barcode (QR Code)
  • Buka halaman detail perangkat yang baru dibuat.
  • Unduh aset QR Code (SVG atau PNG) untuk dicetak ke kartu akrilik atau stiker kemasan.
  • Pada kotak "URL Tag NFC", salin link redirect NFC, formatnya:
    https://domain-anda.com/r/DEV-820192?t=nfc
Langkah 3 Pemrograman (Flashing / Writing) ke Chip NTAG213
  • Buka aplikasi NFC Tools di smartphone Android / iPhone Anda.
  • Pilih menu Write → klik Add a record → pilih Custom URL / URI.
  • Tempelkan (Paste) URL NFC perangkat tadi (pastikan menggunakan protokol https://).
  • Klik tombol Write, lalu tempelkan kartu NTAG213 ke punggung HP hingga muncul tanda centang hijau Write Complete!.
Catatan Keamanan Produksi: Setelah kartu terbukti berfungsi normal, gunakan opsi Lock Tag agar chip bersifat Read-Only dan tidak bisa ditimpa oleh pihak tidak bertanggung jawab saat sudah di meja kasir toko.
Langkah 4 Pengemasan & Penyerahan ke Pemilik Bisnis
  • Cetak atau sertakan Kode Kartu (Activation Code) pada amplop/kemasan fisik kartu.
  • Kirimkan paket fisik ke Pemilik Bisnis. Kartu siap untuk diaktivasi mandiri oleh pembeli.
B
2. Panduan Pengguna: PEMILIK BISNIS (Merchant)
Cukup dilakukan 1 KALI saat menerima kartu fisik. Tidak memerlukan install aplikasi apapun.
Langkah 1 Penerimaan & Pemindaian Pertama (First Tap / Scan)
  • Keluarkan kartu fisik dari kemasan.
  • Pilih salah satu metode di smartphone Anda:
    • Opsi NFC: Tempelkan punggung smartphone Anda ke kartu.
    • Opsi Barcode: Buka kamera HP Anda dan arahkan ke QR Code pada kartu.
  • HP Anda akan secara otomatis membuka peramban (browser) menuju halaman aktivasi Reviewin.
Langkah 2 Login / Pendaftaran Akun Pemilik Bisnis
  • Jika belum masuk, masukkan email & password akun Anda, atau klik Daftar Akun Baru.
  • Setelah berhasil login, formulir aktivasi perangkat akan otomatis ditampilkan.
Langkah 3 Verifikasi Kode Kartu & Hubungkan Lokasi Google Review
  • Kode Kartu: Masukkan kode aktivasi fisik yang tercantum di kemasan (contoh: ACT-492019).
  • Pilih Toko: Pilih nama profil bisnis Anda, atau daftarkan nama bisnis baru jika ini adalah cabang baru.
  • Google Place ID / Link Review: Masukkan Google Place ID atau link profil Google Maps bisnis Anda.
  • Klik tombol "Aktivasi Perangkat Sekarang".
Otomatisasi Sistem: Pada detik tombol aktivasi ditekan, status kartu di server langsung berubah menjadi ACTIVE. Mulai detik ini, NFC DAN BARCODE OTOMATIS AKTIF BERSAMAAN tanpa perlu setting ulang!
Langkah 4 Penempatan Kartu & Monitoring Statistik Toko
  • Letakkan kartu/standee akrilik di tempat yang strategis (area meja kasir, dekat mesin EDC, atau meja makan tamu).
  • Pemilik bisnis dapat masuk ke Portal Merchant kapan saja untuk melihat grafik kunjungan, total tap NFC, total scan barcode, dan analitik ulasan yang masuk.
C
3. Panduan Pengguna: PELANGGAN TOKO (Customer)
Pengalaman ulasan instan < 2 detik tanpa install aplikasi dan tanpa login portal.
Pilihan A Memberikan Review via Tap NFC (Paling Cepat)
  • Pastikan smartphone memiliki fitur NFC aktif (pada iPhone XS ke atas otomatis aktif).
  • Cukup tempelkan smartphone ke logo NFC pada kartu selama 1 detik.
  • Pop-up Google Review toko langsung muncul otomatis di layar HP.
  • Beri rating Bintang 5, ketik komentar ulasan, lalu tekan Posting / Kirim.
Pilihan B Memberikan Review via Scan Barcode (Alternatif Universal)
  • Digunakan untuk pelanggan dengan model smartphone yang belum mendukung NFC.
  • Buka aplikasi Kamera bawaan HP, arahkan lensa ke QR Code pada kartu.
  • Ketuk notifikasi tautan yang muncul di layar.
  • Halaman Google Review toko langsung terbuka seketika untuk diisi ulasan.
Pusat Bantuan & Kendala Umum (Troubleshooting):
  • HP tidak merespon saat Tap NFC: Pastikan layar HP menyala (tidak terkunci) dan tempelkan di posisi sensor NFC HP (iPhone ada di bagian atas belakang, Android umumnya di bagian tengah/kamera).
  • Toko pindah lokasi / ganti nama: Pemilik bisnis tidak perlu ganti kartu fisik! Cukup edit Google Place ID di Portal Merchant, kartu lama otomatis mengarah ke link baru.
